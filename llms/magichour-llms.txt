## About Us

Magic Hour is an all-in-one virtual studio for creating, editing, and enhancing videos, images, and audio with generative AI—no technical expertise required. Creators, marketers, and businesses use it for social content, ads, localization, and creative automation. Many tools work free in the browser without sign-up; paid plans unlock higher quality, volume, and commercial use. Developers integrate the same capabilities via API.

## API & Agent Integration

For AI coding agents and automation:

- **OpenAPI**: [https://magichour.ai/docs/api/openapi.json](https://magichour.ai/docs/api/openapi.json)
- **Auth**: `Authorization: Bearer mhk_live_*`
- **Get API key**: [https://magichour.ai/developer](https://magichour.ai/developer) - set `MAGIC_HOUR_API_KEY` in your environment
- **Docs MCP** (search docs): `claude mcp add --transport http MagicHour https://docs.magichour.ai/mcp`
- **Action MCP** (call API): [https://mcp.magichour.ai](https://mcp.magichour.ai) with the same Bearer key - for Claude Code/Codex locally ([magic-hour-mcp](https://github.com/magichourhq/magic-hour-mcp)). No OAuth yet (web Claude/GPT not supported).
- [Quick Start](https://docs.magichour.ai/get-started/quick-start): Generate an API key and make your first call.
- [Docs llms.txt](https://docs.magichour.ai/llms.txt): Full API endpoint index for agents.
